## 2. 系统概览

- **Product 轨**：RetailGraph（只读、只能提议）→ OperationWorkflow（HMAC grant、一次性 nonce、申请/审批分离、first-decision-wins、幂等重试）→ QueryEngine（AST 白名单 + EXPLAIN 阈值 + 对账）→ `ops_read` 屏障视图；提案/执行/审计全链留痕，身份列裸投影在策略层被拒。
- **BIRD 轨**：EvaluationRunner（任务级恢复、同题双模式串行守卫）→ 官方 ADK 编排器子进程（stdout/stderr 落盘）→ 三容器拓扑（system-agent / user-simulator / db-env）；agent 零 GT 可见性（9 条契约断言 + 运行时拒绝检查）。
- **模型网关**：能力/价格快照驱动（供应商更名 2026-09-10 实测零代码切换）、canonical JSON 请求绑定、逐轮费用估算、协议诊断插桩、fail-closed。
- **遥测**：agent spool JSONL（逐轮 token/费用/band）→ fail-closed 导入 eval 库；UI 评测中心读真实数据。

## 3. 评测结果与结论

### 3.1 BIRD A4 Full（600 题目标）

- **c 批 300/300 任务完成**（12×25 子批 + 4 集余额失败重试 sweep + 1 infra 重试 = 305 attempts，300 succeeded / 4 failed / 1 infra；agent $3.46 = $0.0113/成功任务）；**a 批 223/300**（225 attempts，$6.15 = $0.0273/attempt；75 集经预算裁定截停，2 集确定性 `ContextBudgetExceeded`——a 模式长对话强制上下文超 64K prompt 预算，修复需动冻结的输出水位线，裁定不修）。
- **有效评分 523 条 reward>0 = 0**（A4；2 个 a 失败集无评分）；含消融 120 条有效评分后仍 0 正值。能力门未达。
- **机制（决定性发现）**：官方 c 模式相位记录不携带任务问题 + 我方 adapter 上下文重建缺陷 → 逐轮失忆（Day 6 定位并修复）；修复后失败收敛于**领域知识缺口**——知识查询 miss/定义不全 → agent 自造公式 → user-simulator 拒答 → Phase 1 失败。a 模式诊断同源（探索 SQL 全对、公式靠猜）。

### 3.2 消融 §17.2（执行反馈修复）

30 配对题 × c/a × A/B = **120/120 succeeded**。A（首次失败停止）vs B（官方有限修复）：**P1 完全相同（0/60 vs 0/60）——修复救回 0 集**；B 多耗费用 ~2.4–2.7×、轮次 ~1.37×。结论：当前能力水平下修复价值为零（本样本描述性结论，§17.2 明文不做普遍化），修复的无效性限于该失败层。

### 3.3 产品评测 §17.1（小 Schema 是否需要检索）

题集从零构建（50 题中文问题 + 参考 SQL；三层验证 = 真实库执行 + AST 策略合规 + QueryEngine 结果边界自评分；zh glossary 术语桥；行序契约逐题声明）。A/B×40 + 封闭 10（胜者配置）：

| 条件 | 正确 | 可执行 | Recall@5 | tokens |
|---|---|---|---|---|
| A 全量 Schema | 5/40（12.5%） | 7/40 | 1.000 | 170,696 |
| B BM25 检索（top-5、相对分 ≥0.3） | 4/40（10.0%） | 4/40 | 0.910 | 64,046（−62.5%） |

正确数为审查更正后的重评分口径（对保存 SQL 免费重放；原始执行轮为 3/40、2/40，差异来自评分器假阴性修复，见 §7）。**预注册判据否决检索路线，全量 Schema 胜出**——与 §10.2 预期一致（小 Schema 下全量更有效），检索省 62.5% 总 token 但丢表覆盖。构建期发现并修复产品真缺陷：查询策略函数白名单误杀布尔运算符（AND/OR 查询全部不可执行）。

### 3.4 诚实边界

- reward=0 是评测的真实结果；所有「成功」结论限于工程与流程维度（succeeded 率、机制定位、成本控制）。
- 产品评测为**单步 SQL 生成配置**（无 SqlReasoner 修复环、无多步调查）；策略合规缺口 ~60% 是该配置的如实测量，非产品全链路能力。
- a 批截停、2 集不修、题集由同一系统构建——全部为明示裁定并留痕，非隐藏失败。
