## 2. rewards 全 0 的机制解读（episode 证据）

18 个有效完成集（9 a + 9 c）全部 reward=0.0、phase1/phase2 全 False。episode `tool_trajectory` 聚合给出直接机制：

### 2.1 c-mode：澄清循环失控（主因）

- 9 个 c 集 `ask_user` 共 **539 次**（每集 ~60 次，即把官方 max-turns 顶格轮次全部用于提问），`submit_sql` 仅 **1 次**。
- wall clock 547–584s 顶格退出（执行日志已记）与此互证：agent 在澄清模式下陷入「每轮提问」循环，几乎从不进入作答提交。
- 9 集中唯一 1 次 submit_sql 也未通过评审（reward 0）。

### 2.2 a-mode：预算策略与提交行为不匹配（次因）

- `budget_used = 18.0 / 18.0`（bird-coin = 工具调用次数，episode 实证：19 次工具调用 ≈ 18 coin 耗尽）。
- 9 集工具分布：`execute_sql` 83、`get_knowledge_definition` 34、各类 schema 探索 32、`ask_user` 10、**`submit_sql` 10（7/9 集发生提交，其中 2 集各重提 1 次）**。
- 即：a-mode 大多数集**在预算耗尽前完成了提交**，但提交的 SQL 未通过评审；其余集在提交前预算耗尽被预算门停止（final_response：6 集「Budget exhausted. Task ended.」、3 集「Stopped: infrastructure_error:provider_response_invalid」——后者为我方预算门拒绝后续模型调用的 typed 停止，官方编排器仍判会话正常终局）。

### 2.3 系统性结论

1. **不是基础设施故障**：18 集全部端到端正常终局、官方正常评审出 0 分；failed/unfinished 两集为瞬态服务错误（执行日志 §1），不在此列。
2. **差距在任务策略层，且 c/a 两种模式失败机制不同**：c-mode 根本是「不答题」（澄清失控），a-mode 是「答题但不合格 + 预算挤占」。当前 prompt/策略配置下，Full 1200 集外推结果仍将是全 0 分。
3. **待排查的替代假设（Day 6 第一优先）**：提交语义对齐——agent 的 `submit_sql` 动作（或最终答复）是否与官方评审通道的期望格式一致。若通道断裂，则 a-mode「提交也不得分」属集成缺陷而非 SQL 质量，修复优先级和方式完全不同。该排查需对照官方 ADK 的任务终局语义（冻结允许清单内代码），属零付费静态工作。

### 3.2 方法与假设（全部实测锚定）

- **分层数据**：Full 1200 episode = 600 c + 600 a；Pilot 20 集后剩余 **1180 集 = 590 c + 590 a**。
- **每集轮次假设（实测顶格结构）**：c-mode 每集 60 模型轮（9 集中 8 集顶格，1 集 failed 中段 ~33 轮）；a-mode 每集 18 轮（bird-coin 18 固定，9 集实测一致）。结构配平校验：c 8×60 + c-failed 33 + a 9×18 = 675 turn，与 spool 实测总数**精确相等**。
- **分层归属**：小上下文 turn 591 = c-mode 513 + a-mode 早期 78；累积 turn 84 = a-mode 后期。bootstrap 按层重采样：c 集成本 = 60 × small 重采样求和；a 集成本 = (9 × small + 9 × big) 重采样求和（9:9 为 78:84 的近似）。
- **产品与消融**：§17.1 产品 50 题 = A/B 40 题 × 2 条件 + 封闭 10 题一次 = 90 episode（mode 拆分未定 → 保守按全 c 口径）；§17.2 修复消融 120 episode = 60 c + 60 a。合计 210 集。
- bootstrap：seed=7，N=20,000 次重采样，取 95 分位。

### 3.4 判据裁定的三个限定

1. **agent-side-only**：simulator 侧不经过 spool（独立容器，无用量证据）。simulator 每集同样有多轮 LLM 调用（c-mode 每轮答复澄清），若其用量与 agent 侧同量级，总账将 ~2× 越线。**→ 用户余额交叉核对给出 simulator 侧差额后，本表须加该差额重算；核对结果是预算门的权威裁定。**
2. **每集轮次假设外推到 Full**：假设 Full 的 c/a 集轮次与 Pilot 同分布。若策略修复后 c-mode 提交更早（不再顶格 60 轮），实际成本将显著低于上界——上界性质稳健。
3. **汇率 7.07 为指示性**（账本既有口径）；DeepSeek 计费货币为 USD。
